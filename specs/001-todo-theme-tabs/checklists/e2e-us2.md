# Manual E2E Checklist - US2 (Theme Preference)

- [x] Open Settings tab and verify Light, Dark, Device Default options exist.
- [x] Select Light and verify immediate theme update.
- [x] Select Dark and verify immediate theme update.
- [x] Select Device Default and verify app follows device theme.
- [x] Corrupt persisted theme value and restart; verify fallback to Device Default.
- [x] Restart app after each valid selection and verify persistence.
